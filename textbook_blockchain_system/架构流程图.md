## 智能合约数据结构

> TextbookTrading 合约定义了两组核心数据结构，均运用 Solidity struct 类型，通过 mapping 映射实现基于唯一标识的快速存取。

### Textbook 结构体

| 字段名 | 类型 | 说明 |
|--------|------|------|
| textbookId | string | 教材唯一标识 |
| isbn | string | 国际标准书号 |
| version | string | 版本信息 |
| condition | string | 品相等级 |
| initialPrice | uint256 | 初始定价（以分为单位存储，避免浮点精度问题） |
| exists | bool | 存在性标记，区分空映射与已注册教材 |

存储映射：`mapping(string => Textbook) private textbooks`，以 textbookId 为键

### Transaction 结构体

| 字段名 | 类型 | 说明 |
|--------|------|------|
| transactionId | string | 交易唯一标识 |
| textbookId | string | 关联教材标识 |
| buyer | address | 买方区块链地址 |
| offerPrice | uint256 | 买方报价（以分为单位） |
| status | string | 交易状态："pending" 待确认 / "completed" 已完成 |
| timestamp | uint256 | 交易时间戳（区块时间） |
| exists | bool | 存在性标记 |

存储映射：`mapping(string => Transaction) private transactions`，以 transactionId 为键

辅助映射：`mapping(string => string[]) private textbookTransactions`，按教材维度追溯完整交易历史
